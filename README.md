# മലയാളം ബൈബിൾ ക്വിസ്

## ആരംഭിക്കുന്നത്
1. Python ഇൻസ്റ്റാൾ ചെയ്യുക.
2. ഈ ഫോൾഡറിൽ terminal / command prompt തുറക്കുക.
3. `pip install -r requirements.txt` പ്രവർത്തിപ്പിക്കുക.
4. `streamlit run app.py` പ്രവർത്തിപ്പിക്കുക.
5. Browser-ൽ തുറക്കുന്ന വിലാസത്തിൽ ക്വിസ് ഉപയോഗിക്കുക (സാധാരണയായി http://localhost:8501).

## ഫയലുകൾ
- `app.py` — Streamlit വെബ് ആപ്പ്
- `questions.json` — PDF അടിസ്ഥാനമാക്കിയുള്ള 45 ചോദ്യങ്ങൾ
- `used_questions.json` — ഇതിനകം ഉപയോഗിച്ച ചോദ്യങ്ങളുടെ പട്ടിക
- `requirements.txt` — ആവശ്യമായ Python package

## ചോദ്യങ്ങളുടെ ആവർത്തനം
ആദ്യം ഉപയോഗിക്കാത്ത ചോദ്യങ്ങളിൽ നിന്ന് 20 എണ്ണം തിരഞ്ഞെടുക്കും. ചോദ്യബാങ്ക് തീരുന്നതുവരെ പഴയ ചോദ്യങ്ങൾ വീണ്ടും വരില്ല. ബാങ്ക് തീർന്നാൽ തൊട്ടുമുമ്പത്തെ ടെസ്റ്റിലെ ചോദ്യങ്ങൾ ഒഴിവാക്കി പുതിയ ടെസ്റ്റ് ഒരുക്കും.

## ശ്രദ്ധിക്കുക
ഈ പതിപ്പ് നൽകിയ PDF-യിലെ 1 ശമൂവേൽ 8–10 അദ്ധ്യായങ്ങളെ മാത്രം അടിസ്ഥാനമാക്കിയാണ്. PDF-യിലെ ചില വാക്കുകളിൽ extraction/OCR ഇടവേളകൾ കാണുന്നതിനാൽ പ്രസിദ്ധീകരിക്കുന്നതിന് മുമ്പ് ചോദ്യങ്ങളും വചനപരാമർശങ്ങളും ഒരിക്കൽ കൂടി പരിശോധിക്കുക.
